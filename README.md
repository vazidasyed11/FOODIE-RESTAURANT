🍽️ Foodie Restaurant Website
A responsive and interactive restaurant website built using HTML, CSS, and JavaScript.
📌 About the Project
Foodie Restaurant is a frontend web development project that provides a simple and attractive restaurant website. Users can explore food categories, view the menu, read customer reviews, and use the table reservation form.
✨ Features
🏠 Home section with restaurant introduction
🍕 Food categories
🍔 Restaurant menu
💰 Food prices
🎉 Special weekend offer
⭐ Customer reviews
📅 Table reservation form
✅ Form validation
🔔 Booking confirmation
📱 Responsive design
🖱️ Interactive food and category cards
🔗 Smooth navigation
🛠️ Technologies Used
HTML5
CSS3
JavaScript
Unsplash Images
